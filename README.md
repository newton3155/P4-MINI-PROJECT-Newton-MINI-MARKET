# P4-MINI-PROJECT-Newton-MINI-MARKET
A C-based Mini Market Management System using structs, arrays, pointers, and functions to manage products, stock, member points, and transactions. Includes product price updates and product name corrections.

TASKS DONE:
Task 2: Update Product Name
The program allows the user to change a product's name using pointers and the strcpy() function. The updated name is stored in the original product array.
Task 3: Redeem Points for Discount
The program gives a 10% discount to members who have at least 1,000 points. After redeeming, 1,000 points are deducted from the member's points balance.
Bonus Challenge: Interactive Menu (CLI Looping):
The program uses a while loop to keep running until the user chooses the exit option. It displays a menu, accepts user input using scanf(), and uses a switch-case statement to perform the selected operation. This makes the mini market application interactive and easier to use.
