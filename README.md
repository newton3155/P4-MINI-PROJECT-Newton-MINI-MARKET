# P4 MINI PROJECT: Newton Mini Market

## Project Description
A C-based Mini Market Management System using structs, arrays, pointers, and functions to manage products, stock, member points, and transactions.

## Tasks Completed

### Task 2: Update Product Name
The program allows the user to change a product's name using pointers and the `strcpy()` function. The updated name is stored in the original product array.

### Task 3: Redeem Points for Discount
The program gives a 10% discount to members who have at least 1,000 points. After redeeming, 1,000 points are deducted from the member's points balance.

### Bonus Challenge: Interactive Menu
The program uses a `while` loop to keep running until the user chooses the exit option. It accepts user input using `scanf()` and uses a `switch-case` statement to perform the selected operation.

## Program Results
The program successfully allows users to view products and members, purchase products, update product names, redeem points for discounts, and navigate the application through an interactive menu.
